# Playwright TypeScript - Page Object Model
 
 This repository demonstrates how to set up and use Playwright with TypeScript, following the Page Object Model (POM) approach for testing a login page. The project includes test setup, teardown, reusable utilities, test data, screenshots on failure, and HTML test reports.

 ## Project Structure
 
 ```
project-root/
├── playwright.config.ts          # Playwright configuration
├── src/
│   ├── data/
│   │   └── user.ts               # Data object for a user
│   │   └── course.ts             # Data object for a course
│   │   └── assignnment.ts               # Data object for a assignment
│   ├── pages/
│   │   └── BasePage.ts           # Base page parent class which contains methods/selectors shared by all pages
│   │   └── textbookPage.ts       # Textbook Page parent class that contains methods/selectors for all Overview Textbook pages
│   │   └── loginPage.ts          # Page Object Model for the login page
│   │   └── Other Page Object Model files
│   ├────── TextbookPages/        
│   │        └── Textbook Page Object Model files
│   ├── tests/
│   │   └── loginTest.spec.ts     # Login test cases
│   │   └── Other tests
│   ├── utils/
│   │   ├── testBase.ts           # Base utilities
│   │   ├── testData.ts           # Test data
│   │   ├── Other utility files
│   ├── reports/                  # Test reports generated by Playwright
│   ├── screenshots/              # Failure screenshots
├── tsconfig.json                 # TypeScript configuration
├── README.md                     # Documentation
├── package.json                  # Dependencies and scripts
├── package-lock.json             # Dependency lock file

 ```

## Prerequisites

### Ensure the following are installed on your system: 

1. Node.js (version 16+ recommended)

2. Playwright (installed via npm)

3. Browsers (installed via Playwright CLI)

## Installation

1. Clone this repository:

```
git clone https://github.com/tripleten-externships/Runestone-Academy-Test-Suite.git
cd Runestone-Academy-Test-Suite
```

2. Install dependencies:

```
npm install
```

3. Install Playwright browsers:

```
npx playwright install
```

## Configuration

# Playwright Config

The ***playwright.config.ts*** file includes settings for:

- Base URL (http://ec2-18-209-57-71.compute-1.amazonaws.com)

- Retries (1 retry on failure)

- Screenshots (only-on-failure)

- Trace generation (retain-on-failure)

- HTML reporting

## Running Tests

### Run all tests: 
```
npx playwright test
```

### Run tests with a specific tag (if tagging is implemented):
```
npx playwright test --grep @login
```
### Generate and view the test report:
```
npx playwright show-report
```
### Open Playwright UI to run tests:
```
npx playwright test --ui
```
